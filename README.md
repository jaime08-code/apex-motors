# APEX MOTORS

## Descripción del proyecto

APEX MOTORS es una página web de un concesionario especializado en vehículos deportivos y de alta gama.

El proyecto se ha desarrollado utilizando HTML y CSS, con un diseño moderno basado en tonos oscuros y detalles dorados.

## Páginas del sitio web

- **Inicio:** presentación del concesionario.
- **Galería:** selección de 12 vehículos deportivos.
- **Presupuesto:** formulario para solicitar información y presupuesto.
- **Contacto:** dirección, teléfono, correo electrónico y mapa de ubicación.

## Tecnologías utilizadas

- HTML5
- CSS3
